# 运河多式联运履约

管理平陆运河相关江海联运路线、资源、单证和交付承诺。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括出口货主、运河调度单位、港口与承运企业、境外收货方。

资料所依据的领域事实如下：

- 通航后汽车散件经运河发往东盟组装线
- 六堡茶新路线减少绕行和多次中转
- 合作方式还包括海铁联运、跨境班列和海外仓

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
